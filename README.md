## Project Overview

This repository contains my practical coursework for MIT 8103 Advanced Database Systems, using Kart Direct Courier as a simulated e-commerce and delivery business.

The project demonstrates the application of advanced database concepts using PostgreSQL and MongoDB.

## Portfolio Structure

### Portfolio 1 – Database Design
Relational database design, schema creation, entity relationships, and database implementation using PostgreSQL.

### Portfolio 2 – Query Optimisation
SQL queries, query execution plans, indexing, and performance optimisation.

### Portfolio 3 – Transactions and Concurrency
Database transactions, transaction control, rollback operations, and concurrency management.

### Portfolio 4 – NoSQL
Implementation of a document-oriented database using MongoDB, including collections, embedded documents, and practical evidence.

### Portfolio 5 – Distributed and Cloud Databases
Implementation and testing of PostgreSQL logical replication, including publication, subscription, data synchronisation, and discussion of distributed database concepts.
